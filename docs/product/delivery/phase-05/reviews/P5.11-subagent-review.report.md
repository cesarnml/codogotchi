**Actionable findings**

**Finding #1 — Empty-string `CODOGOTCHI_HOME` produces CWD-relative URL**
- **File:** `apps/menubar/Sources/MenubarMenu.swift:80`
- **What is wrong:** `String(validatingUTF8: cStr)` succeeds on `""` and the early-return fires, yielding `URL(fileURLWithPath: "", isDirectory: true).appendingPathComponent("pets")` — a path relative to the process CWD, not the user home. The "Reveal pet folder" action would open an arbitrary directory.
- **Clause:** Finding-discipline clause 2 — demonstrable correctness gap (degenerate URL silently passed to `workspace.open`).
- **Fix:** Add an `.isEmpty` guard so the env-var path is only taken when `home` is non-empty:
  ```swift
  if let cStr = getenv("CODOGOTCHI_HOME"),
     let home = String(validatingUTF8: cStr),
     !home.isEmpty {
  ```
  The same one-line fix applies to `PetConfig.configURL()` (line 22) and any other callers using the same pattern, though those are outside this ticket's scope.

**Finding #2 — `CODOGOTCHI_HOME` branch in `defaultPetFolderURL()` is untested and CI-environment-sensitive**
- **File:** `apps/menubar/Tests/MenubarTests/MenuItemsTests.swift:213–215`
- **What is wrong:** (a) `testDefaultPetFolderURLPointsToCanonicalPets` never calls `setenv("CODOGOTCHI_HOME", …)`, so the env-var branch introduced in this diff is completely unexercised. A regression (e.g., accidentally returning `/custom/home` instead of `/custom/home/pets`) would not be caught. (b) The test does not unset `CODOGOTCHI_HOME` before calling `defaultPetFolderURL()`, so it is sensitive to whatever the CI runner environment contains.
- **Clause:** Finding-discipline clause 2 — demonstrable correctness gap (new code path with zero test coverage; test result can vary by runner environment).
- **Fix:** (a) Wrap the existing test body in `unsetenv("CODOGOTCHI_HOME")` + restore, mirroring the pattern in `PetConfigTests.swift:84–87`. (b) Add a parallel test that calls `setenv("CODOGOTCHI_HOME", "/custom/home", 1)`, asserts `defaultPetFolderURL().path == "/custom/home/pets"`, and restores the env var in `defer`.
