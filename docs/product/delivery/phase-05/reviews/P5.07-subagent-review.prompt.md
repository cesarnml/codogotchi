### Invariants to hold

1. `PetImportHelper.importPet(id:)` must copy ALL files from the Codex source directory to the canonical destination; after import the app must not read from the Codex path at runtime. If `importPet` silently succeeds without copying, or if any path resolves back to `~/.codex/` at runtime, the invariant is broken.
2. `SettingsController.runHooksInstall()` must invoke the subprocess with `["codogotchi", "hooks", "install"]` and `runHooksUninstall()` with `["codogotchi", "hooks", "uninstall"]`. Neither method may invoke the other's command. A swapped argv breaks the invariant.
3. The Settings window must open without consulting RPG/Convex config — `SettingsWindowController.show()` must succeed on a greenfield machine where no `rpg_enabled` config exists.

### Attack surfaces to probe

1. **`PetImportHelper.importPet` — destination directory removal before copy**: the method calls `removeItem(at: destination)` before `copyItem`. If `removeItem` throws (e.g., partial-write failure after prior interrupted import), the entire `importPet` throws and leaves no destination. Is there any partial-state recovery, or does the caller observe a missing destination after an interrupted double-import?

2. **`PetImportHelper.importPet` — `isDirectory: true` path component**: `codexPetsRoot.appendingPathComponent(id, isDirectory: true)` adds a trailing slash on some macOS versions; `fileManager.fileExists(atPath: source.path)` may behave differently for path-with-slash vs path-without-slash. Probe whether the existence check is reliable for both forms.

3. **`SettingsWindowController.openWindow` — `appStateLoader` called on main thread during window open**: `appStateLoader` is invoked synchronously from `openWindow()` which is on `@MainActor`. The default loader calls `AppStateStore.load` which does file I/O. Is there a risk of main-thread I/O block that could freeze the UI?

4. **`MenubarMenu.build()` — `refreshFloatingPetMenuItemTitle` hardcoded index 2**: `refreshFloatingPetMenuItemTitle` accesses `builtMenu.items[2]` directly. After adding the Settings item (index 3), the floating pet toggle is still at index 2 — but confirm the index is not off-by-one and that the count guard `builtMenu.items.count > 2` still covers all items correctly.

5. **`SettingsController.runHooksInstall/Uninstall` — synchronous subprocess on main thread when called from `SettingsWindowController`**: `handleInstallHooks` and `handleUninstallHooks` dispatch to `DispatchQueue.global(qos: .userInitiated)` before calling the synchronous `runner`. Probe whether a slow or hung subprocess can block the global queue without any timeout, and whether the `[weak self]` capture is sufficient to prevent a retain cycle.

6. **`PetImportHelper.availableCodexPets` — `.isDirectoryKey` resource value on symlinks**: if `~/.codex/pets/` contains symlinks to directories, `isDirectory` may return false depending on how `contentsOfDirectory` resolves them. Probe whether symlinked pet directories are silently excluded from the import list.
