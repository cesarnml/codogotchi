### Diff context

`apps/menubar/Sources/Pool/SessionLifecycle.swift` (new, 55 lines): a `SessionLifecycle` enum (`.active`, `.live`, `.archived`, `.pruned`) with a single `static func classify(age:isRendered:isConcealed:liveTTL:archiveTTL:) -> SessionLifecycle` pure function. Precedence: `age >= archiveTTL` → `.pruned` first (regardless of render/conceal state); else `isRendered` → `.active`; else `isConcealed && age < liveTTL` → `.active`; else `age < liveTTL` → `.live`; else `.archived`. All comparisons are strict `<`.

`apps/menubar/Sources/Settings/SessionsTabViewModel.swift` `refresh()`: previously, for each `state.d/` slice entry, computed `age` from mtime, filtered out `age >= archiveTTL` via an early `guard ... else { continue }`, then ran a 6-branch `if/else if` chain checking `activeWindowKeys.contains(key)`, `hiddenWindowKeys.contains(key) && age < liveTTL`, `pendingShowKeys.contains(key) && age < liveTTL`, `ttlDismissedKeys.contains(key) && age < liveTTL`, `age < liveTTL`, else — each branch appending a `SessionRow` to `active`/`live`/`archived` with a specific `tier`/`isShown` combination, and the first two branches also called `pendingShowKeys.remove(key)`.

After the diff: the same four boolean lookups (`isRendered`, `isHiddenByUser`, `isPendingShow`, `isTtlDismissed`) are computed up front, `SessionLifecycle.classify` is called once with `isConcealed = isHiddenByUser || isPendingShow || isTtlDismissed`, the early continue is now `guard lifecycle != .pruned else { continue }` (moved after the classify call, so `key` is now computed even for entries that will be pruned — a harmless reordering, no behavior change), and a `switch lifecycle` replaces the `if/else if` chain — the `.active` case still has its own internal `if isRendered { } else if isHiddenByUser { } else if isPendingShow { } else { }` to reproduce the original per-branch `isShown`/`pendingShowKeys.remove` semantics, since the classifier itself is agnostic to *which* concealment reason applied.

No other file changed. Full existing Swift suite (1038 tests) passes unmodified after this diff; `SessionsTabViewModelTests` and any `FloatingPetWindowPool`/`MenubarMenu` tests were not edited.
