**Actionable findings**

1. `apps/menubar/Sources/Settings/CustomizationTabViewModel.swift:167,201-205,244-247` — `isApplyingOwnWrite` suppresses unrelated re-entrant publications. Two distinct stores initialized against the same file can therefore lose modes despite `ConfigFileWriter.merge` re-reading the outer JSON object: initialize A and B empty, have A set `claude_code`, then B set `cursor`; B writes a map containing only `cursor`, deleting A’s value.
