### Diff context

This ticket adds config/type/template/parser/reconciliation scaffolding for a new pre-PR
"Refactor leg" cold-read subagent gate, analogous to the existing adversarial
`subagent-review` gate but scoped to local code-quality signals instead of correctness.

Key changes:
- `tools/delivery/config.ts`: adds `VALID_REFACTOR_REVIEW_VALUES = ['disabled', 'runner_on_red']`,
  a `RefactorReviewValue` type, `ReviewPolicy.refactorReview?`/`ResolvedReviewPolicy.refactorReview`
  fields, validation in `parseReviewPolicy` (new `refactorReview` KNOWN_KEYS entry + separate
  validation block since its valid-value set differs from `VALID_REVIEW_POLICY_STAGE_VALUES`),
  and default resolution (`?? 'disabled'`) in `resolveOrchestratorConfig`.
- `tools/delivery/runtime-config.ts`: re-exports the new type/const from the barrel.
- `tools/delivery/types.ts`: adds 7 new optional `TicketState` fields mirroring the adversarial
  gate's naming convention (`refactorReviewOutcome`, `refactorReviewCompletedAt`,
  `refactorReviewPatchCommits`, `refactorReviewAgent`, `refactorRunnerArtifactPath`,
  `refactorReviewPromptPath`, `refactorReviewPromptWrittenAt`), importing `SubagentRunnerOutcome`
  from `subagent-runner.ts`.
- `tools/delivery/refactor-review.ts` (new module): `parseRefactorSuggestions` (tag-based
  extraction of `<refactor-suggestions>...</refactor-suggestions>`, distinguishing found/closed/
  isExplicitNone/suggestions), `isSuspiciousRefactorSuggestionsParse` (0-parse floor check),
  `validateRefactorSuggestionDecision` (reason-required-for-reject/defer), and
  `detectRefactorReviewLabeledCommits`/`reconcileRefactorReview` (Condition A/B reconciliation

  pattern and the new tag parser instead of the heading-based `parseActionableFindings`).
- `docs/template/delivery/refactor-review-template.md` (new): the subagent prompt template with
  the copy-me `<refactor-suggestions>` skeleton.
- No CLI commands, no state persistence, no gate wiring into `open-pr`/`cli-runner.ts` — that is
  explicitly out of scope for this ticket (20.02/20.03 own it).
