### Diff context

The Settings window was a single `SettingsContentView` inside an `NSPanel` stacking three
sections (Hooks, Pet, Alive-RPG) in a scroll view. The rewrite promotes it to an `NSWindow`
hosting an `NSTabView` with four `NSTabViewItem`s whose `identifier` is the `SettingsTab`
raw value. Hooks content moved verbatim into a private `GeneralTabView`, Pet content into a
private `PetTabView`, a new placeholder `DeveloperTabView`, and a new `AboutTabView` that
reads `AboutViewModel.appVersion` / `.hookVersion`. The Alive-RPG section is deleted. A pure
`SettingsTabModel` owns tab order + selection and is kept in sync from the `NSTabViewDelegate`
callback. On the CLI side, `dispatch` gained an early `--version`/`-v`/`version` branch that
prints `CLI_VERSION` ("0.0.0") and exits 0; `AboutViewModel.bundledHookVersion` shells out to
`codogotchi --version` via the injectable `HookStatusClient.Runner`.
