### Ticket scope

P8.02 — Bundle-first resolution + absolute hook path. Outcome:
- When running as a compiled bundled binary, `installHooks` writes the **absolute path** to the
  sibling `codogotchi-hook` (resolved from `process.execPath`'s directory) into every platform
  surface (Claude `settings.json`, Codex `hooks.json`, Codex TOML) instead of the bare
  `codogotchi-hook` name.
- In a dev build (no compiled bundle), install falls back to the bare `codogotchi-hook` name
  (current behavior) — preserved for `bun` development.
- Swift `defaultRunner` (`HookStatusClient`) resolves the `codogotchi` binary from `Bundle.main`
  `Contents/Resources/` first, falling back to PATH (`/usr/bin/env`) only when the bundled copy
  is absent (dev).
- Re-running install remains idempotent: the absolute path replaces any prior codogotchi matcher
  (bare or absolute) with no duplicate entries.

Rationale notes: bundle-vs-dev is discriminated by an on-disk check for the sibling
`codogotchi-hook` next to `process.execPath`; callers pass `process.execPath` unconditionally.
Resolution is centralized in `resolveHookCommand(execPath?)`. Cursor (`installCursorHooks`) is
intentionally out of scope (Outcome enumerates only the three Claude/Codex surfaces). Any
resolved absolute path still ends in `codogotchi-hook`, so `isCodogotchiCommand` substring
detection keeps working for both bare and absolute forms.

### Invariants to hold

1. `installHooks({ execPath })` writes the absolute path `join(dirname(execPath), "codogotchi-hook")`
   into the Claude matcher command, the Codex TOML `command = ...` literal, and the Codex hooks.json
   command **iff** that sibling file exists on disk; otherwise (no `execPath`, or sibling absent) it
   writes the bare string `codogotchi-hook`.
2. After any install, each Claude/Codex codogotchi event slot contains exactly one codogotchi matcher
   whose command is the currently-resolved command — re-running install (bare→absolute, absolute→absolute,
   absolute→bare) never leaves a duplicate or stale codogotchi entry.
3. `HookStatusClient.resolveRunnerLaunch(argv:resourceURL:fileExists:)` returns
   `(resourceURL/<head>, argv.dropFirst())` when `resourceURL != nil` and the bundled file exists, and
   `("/usr/bin/env", argv)` in every other case (nil resourceURL, or file absent, or empty argv).
