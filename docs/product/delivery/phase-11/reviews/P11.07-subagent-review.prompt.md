### Invariants to hold

1. Authoring is gated server-side: `generateUploadUrl` (convex/pets.ts) and `uploadPet`
   (convex/actions/uploadPet.ts) both throw when `getAuthUserId(ctx)` is null. Read paths
   (listPets, listPetsForGallery, getPet, the /pets/<id>/download HTTP route) require no auth.
2. Username uniqueness is enforced server-side on the normalized (trimmed, lowercased) form:
   `users.setUsername` throws `usernameTakenMessage(normalized)` when the normalized handle
   belongs to a different userId, and `validateUsername` rejects shape violations before any
   DB write. Case/whitespace variants of an existing handle cannot create a second identity.
3. A missing or failed client thumbnail never blocks a valid upload: `generateThumbnailFromZip`
   returns null on any error, `buildUploadArgs` omits `thumbnailStorageId` when absent, and
   `uploadPet` still succeeds (thumbnail is optional + size-capped server-side).

### Attack surfaces to probe

Surfaces for this review:

5. `web/src/lib/uploadMapper.ts mapUploadError` — does it surface ConvexError `.data`
