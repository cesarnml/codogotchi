**Actionable findings**

- `apps/menubar/Sources/App/MenubarApp.swift:297`, `:351`, and `:747`, together with `apps/menubar/Sources/Pool/FloatingPetWindowPool.swift:804-810` and `:905-911` — storing proxies changes observable controller identity and concrete type. Fix by targeting the already-known `WindowKey` in hide callbacks and providing an intentional raw-controller access mechanism for concrete controller operations, or otherwise preserving the existing lookup semantics while keeping recording internal.

- `apps/menubar/Sources/Pool/FloatingPetWindowPool.swift:898-902` — missing `minimalistWindowFactory` for a combined-minimalist spawn returns from `update()`, so that poll tick never runs the shadow and also skips the old pipeline’s subsequent RPG push phase. This breaks invariant 4 and the “every poll tick runs both pipelines” contract. Restructure the combined spawn branch to log and skip only the spawn, allowing the old epilogue and `runShadowTick` to execute.

- `apps/menubar/Sources/Pool/PoolShadowComparator.swift:59-66` — keys present on only one side are deliberately ignored. A missing or spurious window is one of the most consequential pipeline divergences, yet it produces no record; it also masks the reconstruction loop’s silent omission of a non-proxy controller. This is a demonstrated correctness gap in the comparator contract. Emit a structured membership divergence for one-sided keys, with tests for both old-only and new-only membership.

- `apps/menubar/Sources/Pool/Derive/ShadowTickFingerprint.swift:13-20` — the claimed replayable fingerprint contains only time plus each key’s activity state and `updatedAt`. It omits customization, assignments, source events, attention, gate badges, RPG state, HUD mode, session effect-seam values, and idle-escalation inputs, all of which can change `derive` output. Two materially different tick inputs can therefore produce the same fingerprint, preventing replay of logged divergences. This is a correctness gap against the ticket’s replayability requirement. Fingerprint a deterministic canonical representation or digest of the complete `PoolTickInput`, with sensitive values hashed or length-redacted.

- `apps/menubar/Sources/Pool/ShadowDivergenceLogger.swift:31` — only `sessionLabel` and `sessionTooltip` are redacted. An `attention` divergence serializes `AttentionPayload.summary`, which is explicitly user-facing free-form text, into both NSLog and disk. This violates the ticket’s “no sensitive content” review contract and is a security/privacy regression. Add field-aware serialization that redacts `attention.summary` while retaining safe structural fields, and add a logger test proving the secret is absent from both rendered values and the file.
