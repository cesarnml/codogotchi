### Diff context

Key changes:
- `FloatingPetWindowPool.update()` now: (1) resets every live `RecordingFloatingPetWindowControllingProxy`'s recorded-call log at tick start; (2) wraps every freshly-spawned real controller (both the direct-key spawn site and the `.combined` spawn site) in that proxy, storing the proxy directly in `windows[key]` so all existing push call sites forward transparently; (3) calls a new private `runShadowTick(snapshot:visibleEntries:currentTime:hudMode:)` at the very end of the method, after every real controller push for the tick has already happened.
- `runShadowTick` builds a `PoolTickInput` from the pool's own already-computed tick-local values (never re-reading `customizationReader()`/`assignmentsReader()`/`now()` a second time), optionally passes it through a test-only `shadowTickInputPerturbation` hook, calls `PoolDerive.derive(input:memory:)` against a persistent `shadowMemory` field, reconstructs each surviving window's "old" `DesiredWindow` via `RecordedPushDesiredWindowReconstruction.reconstruct` (folding `RecordedPush` case-by-case, with `isMinimalist`/`petId`/`promptTimerStatus`/`rpgSnapshot` seeded directly from the pool's own live state rather than parsed from pushes), diffs via `PoolShadowComparator.compare`, and invokes `shadowDivergenceHandler` only when divergences are non-empty. The default handler is `{ _ in }` (no-op); `MenubarApp` wires the real `ShadowDivergenceLogger.log` explicitly.
- `setVisible`, `hideAllOtherWindows`, `pruneSession`, and `resetPromptTimer` each gained one `shadowMemory = shadowMemory.<transition>(...)` call using the already-shipped (P18.02) pure `PoolMemoryUserActions` extension methods, placed adjacent to the existing driving-side mutation.
- `PoolShadowComparator` gained a second named `ShadowCompareExemption` case (`frameProvenanceUnavailableFromRecordedPushes`) and a guard (`old.inheritedFrameFrom != nil`) so the `inheritedFrameFrom` field is never compared when the reconstructed old side (which can only ever be `nil`) would otherwise permanently false-positive against a real `derive`-emitted donor key.
- `RecordingFloatingPetWindowControllingProxy` gained a `resetRecording()` method (clears `recordedCalls`); no other behavior changed.
- `ShadowDivergenceLogger` (new): NSLog + bounded (1MB rotation), redacted (`sessionLabel`/`sessionTooltip` values replaced with a length indicator) append-only log at `~/.codogotchi/logs/shadow-divergence.log`.
