### Invariants to hold

1. `GateJsonReader.read(at:)` must return nil for: missing file, malformed JSON, and JSON that does not contain the required `gate` and `expires_at` fields. It must never throw into the render loop.
2. `resolveActivityState` must return the gate state when and only when: (a) gate is non-nil, (b) `isExpired` returns false, (c) `ActivityState(rawValue: gate.gate)` returns a valid case, and (d) `CodogotchiPet.rowMap[gateState] != nil`. All four conditions must hold; any one failing must cause fall-through to `hookState`.
3. The `LivePollingDriver` must pass `gatePath` and `gateReader` through to `resolveActivityState` on each tick. When `gatePath` is nil, the resolver receives `nil` gate and returns the hook state unchanged.

### Attack surfaces to probe

1. **`isExpired` boundary — fractional seconds vs whole seconds** — `GateSnapshot.isExpired` uses a two-pass ISO 8601 parse. Probe: does `"2026-05-29T12:00:00.000Z"` (fractional) parse on the first pass and `"2026-05-29T12:00:00Z"` (whole seconds) parse on the second? Read `GateJsonReader.swift` `isExpired` implementation.

2. **`resolveActivityState` condition D — CodogotchiPet.rowMap lookup** — after P7.01, the `CodogotchiPet.rowMap` has 8 entries (specific v4 SoA states). Probe: does `advance` (a v4 ActivityState not in rowMap) correctly fall through to hookState? Verify `CodogotchiPet.rowMap` keys and confirm the test at `testUnexpiredGateWithArtlessStateRendersHookState` covers this case.

3. **`resolveActivityState` condition C — unknown gate string** — `ActivityState(rawValue: "some_unknown_gate_state")` returns nil. Probe the nil check path: `ActivityState(rawValue:)` returns `Optional<ActivityState>`; the guard requires `let gateState = ActivityState(rawValue: gate.gate)`. A nil here causes `guard` to fall through to `hookState`. Confirm this chain is correct by reading the implementation.

4. **`LivePollingDriver` — gatePath=nil guard** — when `gatePath` is nil (the default for all test instances that don't supply it), `gatePath.flatMap { gateReader($0) }` evaluates to nil. Probe that existing `LivePollingTests` still pass: they do not pass `gatePath`, so `gate` is always nil, and `resolveActivityState(gate: nil, hookState: ...)` must return `hookState` unchanged.

5. **`MenubarApp.swift` gate path derivation** — the gate path is derived as `config.pollingTarget.deletingLastPathComponent().appendingPathComponent("gate.json").path`. For live mode: `~/.codogotchi/state.json` → parent `~/.codogotchi/` → `~/.codogotchi/gate.json`. For demo mode: `$TMPDIR/codogotchi-demo/state.json` → `$TMPDIR/codogotchi-demo/gate.json`. Probe that the path derivation is correct for both cases. The gate.json will simply not exist in demo mode, which is correct.

6. **Missing required fields in gate.json** — `GateJsonReader` requires `gate`, `since`, and `expires_at`. If `expires_at` is absent, the reader returns nil. Read `GateJsonReader.swift` line by line to confirm the `guard` requiring all three fields.
