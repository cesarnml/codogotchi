Extend verified-state routing to return `write-subagent-refactor-review`, `subagent-refactor-review`, or `reconcile-subagent-refactor-review` as appropriate, while preserving the old route exactly for disabled, Red-skip, and doc-only tickets; add routing tests for each state.

Thus bypass tickets can have prompt, runner, and reconciliation steps attempted despite the outcome saying they bypass structurally with no such attempts. This is a stated-contract break under finding-discipline clause 1. Centralize the existing policy/red/doc-only eligibility decision and apply it both to routing and all three refactor command entrypoints.
